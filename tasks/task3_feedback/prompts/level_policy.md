# Feedback Level Policy — scaffold

This file is the single policy source for all Task 3 experiments.

- Level 1: praise or indicate a problem; no location, specific error name, cause, or concrete fix.
- Level 2: location and cause; no concrete fix, corrected code, or solution.
- Level 3: diagnosis and correction suggestions; no complete solution.
- Level 4: explicit solution and detailed fix where permitted.

Future work must turn these rules into deterministic checks and version the policy with experiments.
